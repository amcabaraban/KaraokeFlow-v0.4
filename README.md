# KaraokeFlow v0.4 UI beta
Buildable Android project for GitHub Actions (Java / Gradle). Includes dark UI home, CSV song catalog import, song search, queue, favorites, and **player preview only**. This is NOT a functioning MIDI player; do not replace the working v0.3 APK. Integrate the matching v0.3 MIDI synthesizer and lyric timeline sources before claiming audio support. Import format uses original 6+ column `mkmd_catalog_probe.csv` mapping: song number column 1, title 3, artist 4, filename 6. Current library and queue are in-memory and reset on restart. Use GitHub Actions artifact `KaraokeFlow-v0.4-UI-APK` after successful build.
